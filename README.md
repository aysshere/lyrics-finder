# 🎧 Şarkı Sözleri Bulucu - by Ayşe

Bu web uygulaması sayesinde sanatçı ve şarkı adı girerek şarkı sözlerini kolayca bulabilirsiniz.

## Özellikler

- Lyrics.ovh API kullanır
- Basit ve şık tasarım
- Türkçe dil desteği
- Özgün yorum cümleleri ile sonuçları renklendirir

🔗 Yayında görmek için: [aysshere.github.io/lyrics-finder](https://aysshere.github.io/lyrics-finder)
